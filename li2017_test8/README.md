# Eighth test: Chong et al.'s report-contingent timing where successive durations are as weakly correlated as observers'

Analysis plan: `analysis_plan_li2017_test8.md` (committed with this code before the run).

    python run_li2017_test8.py --workers 6       # about an hour with 6 workers; writes li2017_test8_results.json
    python analyse_li2017_test8.py               # writes li2017_test8_tests.json

Reads the seventh test's configurations from `../li2017_test7/li2017_test7_results.json` and uses its noise streams,
so the baseline reproduces the seventh test's exactly; the run checks this after each chunk and stops if not. The number of workers does not affect the results. A partial
results file (`li2017_test8_results.json.partial.json`) is written after each model.

Files: `run_li2017_test8.py` (simulation: Chong et al.'s timing at 2.5%, 5%, 7.5%, 10% and 20%), `analyse_li2017_test8.py`
(pre-specified analysis: calibration to a 29% attended lengthening, decisions C1 to C4), and, unchanged from the seventh
test, `li2017.py`, `li2017_t6.py`, `rate_models.py`, `run_li2017_test.py`, `run_li2017_test3.py`, `run_li2017_test6.py`,
`run_li2017_test7.py`, `README_original_Li2017.ME` (licence of the original MATLAB code). `dry8.json`,
`dry8_tests.json`: zero-increment dry run and its analysis. `repro8_check.py`, `repro8_check_sfa.log`: the baseline
reproduction check. `make_synth8.py`, `synth8_*_tests.json`: the analysis checked on synthetic data with known effects (the synthetic inputs, about 30 MB, are regenerated by `make_synth8.py`).
`precheck8.md`, `precheck/`: the pre-run review. `code_sha256.txt`: checksums.
