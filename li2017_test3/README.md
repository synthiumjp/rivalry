# Third pre-registered test in the attention model of binocular rivalry of Li et al. (2017)

Registration text: `prereg_li2017_test3.md` (registered on OSF in the project https://osf.io/kqdgb/).

The port `li2017.py` is that of `../li2017_test2/`, unchanged. The original MATLAB code of Li et al.
(2017) is at https://archive.nyu.edu/handle/2451/38721 and is licensed CC BY-SA 3.0; its README is
included as `README_original_Li2017.ME`, and this port is distributed under the same licence.

| File | Role |
|---|---|
| `run_li2017_test3.py` | the registered simulation: `python run_li2017_test3.py` (about 3 h on 2 cores; `--workers N` for more) |
| `analyse_li2017_test3.py` | the registered analysis: `python analyse_li2017_test3.py` |
| `run_li2017_test.py` | first test's script, used for its helpers |
| `synth_test3.py` | checks the analysis on synthetic data generated by each account (needs `../li2017_test2/li2017_test2_results.json`) |
| `dry3.json`, `dry3_tests.json` | dry run with every increment zero, non-registered seeds, 30 s runs |
| `synth3_summary.json` | outcome of the synthetic check |
| `code_sha256.txt` | checksums of the code and registration at the registered commit |
