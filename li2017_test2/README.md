# Second pre-registered test in the attention model of binocular rivalry of Li et al. (2017)

Registration text: `prereg_li2017_test2.md` (OSF link added after registration).

The port `li2017.py` is that of `../li2017_test/` with one change: a schedule may return a graded
increment level in [0, 1] (for a contrast ramp); for on/off schedules the arithmetic is unchanged.
The original MATLAB code of Li et al. (2017) is at https://archive.nyu.edu/handle/2451/38721 and is
licensed CC BY-SA 3.0; its README is included as `README_original_Li2017.ME`, and this port is
distributed under the same licence.

| File | Role |
|---|---|
| `run_li2017_test2.py` | the registered simulation: `python run_li2017_test2.py` |
| `analyse_li2017_test2.py` | the registered analysis: `python analyse_li2017_test2.py` |
| `run_li2017_test.py` | first test's script, used for its helpers |
| `repro_check.py` | checks the modified port against the first test (run from this folder) |
| `feas_noadapt.py` | pre-registration feasibility check (baseline only, no increment) |
| `synth_test.py` | checks the analysis on synthetic data generated by each account |
| `dry2.json`, `dry2_tests.json` | dry run with every increment zero, non-registered seeds, 30 s runs |
